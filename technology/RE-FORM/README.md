# RE:FORM — Smart knee support and digital rehabilitation

**An early-stage concept exploring stylish recovery support, movement sensing and rehabilitation insights.**

RE:FORM explores how wearable movement signals and a digital experience might help people and physiotherapists understand rehabilitation progress.

## Prototype and experiments
The technical work is maintained in a separate repository:

[Open the RE:FORM prototype repository](https://github.com/armaanachawla/Re-prototype)

The repository includes a frontend prototype and a Python movement-sensing experiment using synthetic two-IMU data.

## Scope note
The movement-sensing experiment uses synthetic data to explore signal processing and knee-flexion estimation. It is not a real-device integration or clinical validation. Hardware testing and real-world validation remain future work.
